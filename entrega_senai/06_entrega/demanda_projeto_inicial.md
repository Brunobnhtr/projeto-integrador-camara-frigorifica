Projeto Integrador 2026/01 6.01 03: Implementação de Sistema de Controle Inteligente com ESP32 para Cabine Climatizada
Descrição resumida:
O processo atual realiza ensaios térmicos em dispositivos energizados via Arduino e acionamento manual, mas carece de monitoramento em tempo real e registro de dados. A proposta é modernizar o sistema utilizando o ESP32, otimizando a infraestrutura elétrica e permitindo a conectividade necessária para integração futura com uma dashboard digital, garantindo melhor gestão e acompanhamento dos testes.


Benefícios esperados:
Aumentar a confiabilidade dos ensaios térmicos;
Melhorar o controle e precisão dos ciclos de temperatura
Permitir monitoramento remoto em tempo real
Possibilitar registro e rastreabilidade dos testes
Reduzir riscos elétricos por meio de melhorias na infraestrutura
Preparar o sistema para integração com ferramentas digitais
Reduzir o tempo de diagnóstico de falhas


Detalhamento:
Atualmente, a empresa realiza ensaios térmicos em dispositivos eletrônicos embarcados, submetendo até 50 unidades simultaneamente a ciclos controlados de aquecimento e resfriamento dentro de uma cabine de climatização. Durante o teste, os dispositivos permanecem energizados e operando em modo de simulação funcional, permitindo a análise de seu comportamento sob variação térmica.

O sistema é composto por:
Microcontrolador responsável pelo controle dos ciclos térmicos
Display local para parametrização
Sistema de climatização da cabine
Disjuntores para energização dos dispositivos
Infraestrutura elétrica de alimentação

Entretanto, foram identificadas oportunidades de melhoria, tais como:
Ausência de monitoramento remoto
Limitação de conectividade
Baixa capacidade de registro de dados
Organização elétrica passível de aprimoramento
Interface de controle limitada

A proposta do projeto é implementar um ESP32, aproveitando sua maior capacidade de processamento e conectividade Wi-Fi/Bluetooth, permitindo futura implementação de dashboard de monitoramento e registro de dados em tempo real.

As etapas previstas incluem:
Testes de bancada com ESP32
Desenvolvimento de novos esquemas elétricos.
Possível protótipo em impressão 3D
Validação de testes

Manter a continuidade operacional do sistema atual durante o desenvolvimento
Necessidade de compatibilidade com a infraestrutura elétrica existente
Tempo limitado para testes e validação
Implementação inicial restrita a ambiente de testes
Garantir conformidade com normas de segurança elétrica
